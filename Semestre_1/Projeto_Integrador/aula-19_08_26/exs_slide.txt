1. Leia o nome de uma pessoa e escreva uma mensagem de boas-vindas: ✅
ALGORITMO
DECLARE nome LITERAL
ESCREVA "Digite seu nome: "
LEIA nome
ESCREVA "Seja bem-vindo(a) ", nome
FIM_ALGORITMO.

2.  Leia dois números e mostre a subtração do primeiro pelo segundo: ✅
ALGORITMO
DECLARE n1, n2, resultado NUMÉRICO
ESCREVA "Digite os dois números: "
LEIA n1, n2
resultado <- n1 - n2
ESCREVA "A subtração foi: ", resultado
FIM_ALGORITMO.

3. Leia a base e a altura de um retângulo e mostre sua área: ✅
ALGORITMO
DECLARE base, altura, area NUMÉRICO
ESCREVA "Digite a base e a altura do seu retângulo: "
LEIA base, altura
area <- base * altura
ESCREVA "A área do seu retângulo é: ", area
FIM_ALGORITMO.

4. Leia três notas e mostre a média aritmética: ✅
ALGORITMO
DECLARE n1, n2, n3, media NUMÉRICO
ESCREVA "Digite as 3 notas: "
LEIA n1, n2, n3
media <- (n1 + n2 + n3) / 3
ESCREVA "A média das notas foi: ", media
FIM_ALGORITMO.

5. Leia o salário de uma pessoa e mostre o salário com aumento de 15%: ✅
ALGORITMO
DECLARE salario, salario_aumentado NUMÉRICO
ESCREVA "Digite o salário: "
LEIA salario
salario_aumentado <- salario * 1.15
ESCREVA "O salário com aumento de 15% será: ", salario_aumentado
FIM_ALGORITMO.
