1) Faça um programa que preencha um vetor com nove números inteiros, calcule e mostre os números
primos e suas respectivas posições.
ALGORITMO
DECLARE A[9],I,J,DIVISORES NUMÉRICO
PARA I<-1 ATÉ 9 FAÇA
INÍCIO
    ESCREVA "INSIRA UM NÚMERO"
    LEIA A[I]
FIM
ESCREVA "NÚMEROS PRIMOS"
PARA I<-1 ATÉ 9 FAÇA
INÍCIO
    DIVISORES<-0
    SE A[I]>1 ENTÃO
    INÍCIO
        PARA J<-1 ATÉ A[I] FAÇA
        INÍCIO
            SE A[I] MOD J=0 ENTÃO
            INÍCIO
                DIVISORES<-DIVISORES+1
            FIM
        FIM
        SE DIVISORES=2 ENTÃO
        INÍCIO
            ESCREVA "NÚMERO PRIMO: ",A[I]," POSIÇÃO: ",I
        FIM
    FIM
FIM
FIM_ALGORITMO.

2) Uma pequena loja de artesanato possui apenas um vendedor e comercializa dez tipos de objetos.
O vendedor recebe, mensalmente, salário de R$ 545,00, acrescido de 5% do valor total de suas vendas.
O valor unitário dos objetos deve ser informado e armazenado em um vetor; a quantidade vendida de
cada peça deve ficar em outro vetor, mas na mesma posição. Crie um programa que receba os preços
e as quantidades vendidas, armazenando-os em seus respectivos vetores (ambos com tamanho dez).
Depois, determine e mostre:
um relatório contendo: quantidade vendida, valor unitário e valor total de cada objeto. Ao final, deverão
ser mostrados o valor geral das vendas e o valor da comissão que será paga ao vendedor; e
o valor do objeto mais vendido e sua posição no vetor (não se preocupe com empates).
ALGORITMO
DECLARE PRECO[10],QUANT[10],I,TOTAL_ITEM,TOTAL_VENDAS,COMISSAO,MAIOR_QUANT,POS_MAIOR NUMÉRICO
TOTAL_VENDAS<-0
PARA I<-1 ATÉ 10 FAÇA
INÍCIO
    ESCREVA "INSIRA O PREÇO UNITÁRIO DO OBJETO"
    LEIA PRECO[I]
    ESCREVA "INSIRA A QUANTIDADE VENDIDA"
    LEIA QUANT[I]
FIM
MAIOR_QUANT<-QUANT[1]
POS_MAIOR<-1
PARA I<-1 ATÉ 10 FAÇA
INÍCIO
    TOTAL_ITEM<-PRECO[I]*QUANT[I]
    TOTAL_VENDAS<-TOTAL_VENDAS+TOTAL_ITEM
    ESCREVA "OBJETO ",I," QUANTIDADE: ",QUANT[I]," PREÇO UNITÁRIO: ",PRECO[I]," TOTAL: ",TOTAL_ITEM
    SE QUANT[I]>MAIOR_QUANT ENTÃO
    INÍCIO
        MAIOR_QUANT<-QUANT[I]
        POS_MAIOR<-I
    FIM
FIM
COMISSAO<-TOTAL_VENDAS*0.05
ESCREVA "VALOR GERAL DAS VENDAS: ",TOTAL_VENDAS
ESCREVA "COMISSÃO DO VENDEDOR: ",COMISSAO
ESCREVA "OBJETO MAIS VENDIDO: POSIÇÃO ",POS_MAIOR," QUANTIDADE: ",MAIOR_QUANT
FIM_ALGORITMO.

3) Faça um programa que, no momento de preencher um vetor com oito números inteiros, já os
armazene de forma crescente.
ALGORITMO
DECLARE A[8],I,J,AUX NUMÉRICO
PARA I<-1 ATÉ 8 FAÇA
INÍCIO
    ESCREVA "INSIRA UM NÚMERO"
    LEIA AUX
    J<-I
    ENQUANTO J>1 E A[J-1]>AUX FAÇA
    INÍCIO
        A[J]<-A[J-1]
        J<-J-1
    FIM
    A[J]<-AUX
FIM
ESCREVA "VETOR EM ORDEM CRESCENTE"
PARA I<-1 ATÉ 8 FAÇA
INÍCIO
    ESCREVA A[I]
FIM
FIM_ALGORITMO.

4) Crie um programa que preencha uma primeira matriz de ordem 4 x 5 e uma segunda matriz 5 x 2. O
programa deverá, também, calcular e mostrar a matriz resultante do produto matricial das duas matrizes anteriores, armazenando-o em uma terceira matriz de ordem 4 x 2.
ALGORITMO
DECLARE A[4,5],B[5,2],C[4,2],I,J,K NUMÉRICO
ESCREVA "INSIRA OS VALORES DA MATRIZ A"
PARA I<-1 ATÉ 4 FAÇA
INÍCIO
    PARA J<-1 ATÉ 5 FAÇA
    INÍCIO
        LEIA A[I,J]
    FIM
FIM
ESCREVA "INSIRA OS VALORES DA MATRIZ B"
PARA I<-1 ATÉ 5 FAÇA
INÍCIO
    PARA J<-1 ATÉ 2 FAÇA
    INÍCIO
        LEIA B[I,J]
    FIM
FIM
PARA I<-1 ATÉ 4 FAÇA
INÍCIO
    PARA J<-1 ATÉ 2 FAÇA
    INÍCIO
        C[I,J]<-0
        PARA K<-1 ATÉ 5 FAÇA
        INÍCIO
            C[I,J]<-C[I,J]+A[I,K]*B[K,J]
        FIM
    FIM
FIM
ESCREVA "MATRIZ RESULTANTE C"
PARA I<-1 ATÉ 4 FAÇA
INÍCIO
    PARA J<-1 ATÉ 2 FAÇA
    INÍCIO
        ESCREVA C[I,J]
    FIM
FIM
FIM_ALGORITMO.

6) Faça um programa que leia um vetor com cinco posições para números reais e, depois, um código
inteiro. Se o código for zero, finalize o programa; se for 1, mostre o vetor na ordem direta; se for 2,
mostre o vetor na ordem inversa.
ALGORITMO
DECLARE V[5],I,OP NUMÉRICO
ESCREVA "INSIRA OS VALORES NO VETOR"
PARA I<-1 ATÉ 5 FAÇA
INÍCIO
    LEIA V[I]
FIM
ESCREVA "EXIBIR O VETOR EM ORDEM DIRETA - 1"
ESCREVA "EXIBIR O VETOR EM ORDEM INVERSA - 2"
ESCREVA "SAIR - 0"
LEIA OP
ENQUANTO OP=1 OU OP=2 FAÇA
INÍCIO
    SE OP=1 ENTÃO
    INÍCIO
        PARA I<-1 ATÉ 5 FAÇA
        INÍCIO
            ESCREVA V[I]
        FIM
    FIM
    SENÃO
    INÍCIO
        I<-5
        ENQUANTO I>=1 FAÇA
        INÍCIO
            ESCREVA V[I]
            I<-I-1
        FIM
    FIM
    ESCREVA "EXIBIR O VETOR EM ORDEM DIRETA - 1"
    ESCREVA "EXIBIR O VETOR EM ORDEM INVERSA - 2"
    ESCREVA "SAIR - 0"
    LEIA OP
FIM
FIM_ALGORITMO.

7) Elabore um programa que preencha uma matriz 6 x 4 com números inteiros, calcule e mostre
quantos elementos dessa matriz são maiores que 30 e, em seguida, monte uma segunda matriz com os
elementos diferentes de 30. No lugar do número 30, da segunda matriz, coloque o número zero.
ALGORITMO
DECLARE M[6,4],N[6,4],I,J,C30 NUMÉRICO
ESCREVA "INSIRA OS VALORES"
PARA I<-1 ATÉ 6 FAÇA
INÍCIO
    PARA J<-1 ATÉ 4 FAÇA
    INÍCIO
        LEIA M[I,J]
    FIM
FIM
C30<-0
PARA I<-1 ATÉ 6 FAÇA
INÍCIO
    PARA J<-1 ATÉ 4 FAÇA
    INÍCIO
        SE M[I,J]>30 ENTÃO
        INÍCIO
            C30<-C30+1
        FIM
        N[I,J]<-M[I,J]
        SE M[I,J]=30 ENTÃO
        INÍCIO
            N[I,J]<-0
        FIM
    FIM
FIM
ESCREVA "MATRIZ NOVA"
PARA I<-1 ATÉ 6 FAÇA
INÍCIO
    PARA J<-1 ATÉ 4 FAÇA
    INÍCIO
        ESCREVA N[I,J]
    FIM
FIM
ESCREVA "TOTAL DE VALORES MAIORES QUE 30: ",C30
FIM_ALGORITMO.

8) Crie um programa que preencha uma matriz 8 x 8 com números inteiros e mostre uma mensagem
dizendo se a matriz digitada é simétrica. Uma matriz só pode ser considerada simétrica se A[i,j] = A[j,i].
ALGORITMO
DECLARE A[8,8],I,J,SIMETRICA NUMÉRICO
ESCREVA "INSIRA OS VALORES DA MATRIZ"
PARA I<-1 ATÉ 8 FAÇA
INÍCIO
    PARA J<-1 ATÉ 8 FAÇA
    INÍCIO
        LEIA A[I,J]
    FIM
FIM
SIMETRICA<-1
PARA I<-1 ATÉ 8 FAÇA
INÍCIO
    PARA J<-1 ATÉ 8 FAÇA
    INÍCIO
        SE A[I,J]>A[J,I] OU A[I,J]<A[J,I] ENTÃO
        INÍCIO
            SIMETRICA<-0
        FIM
    FIM
FIM
SE SIMETRICA=1 ENTÃO
INÍCIO
    ESCREVA "A MATRIZ É SIMÉTRICA"
FIM
SENÃO
INÍCIO
    ESCREVA "A MATRIZ NÃO É SIMÉTRICA"
FIM
FIM_ALGORITMO.

9) Faça um programa que preencha uma matriz 7 x 7 de números inteiros e crie dois vetores com sete
posições cada um que contenham, respectivamente, o maior elemento de cada uma das linhas e o
menor elemento de cada uma das colunas. Escreva a matriz e os dois vetores gerados.
ALGORITMO
DECLARE A[7,7],MAIOR[7],MENOR[7],I,J NUMÉRICO
ESCREVA "INSIRA OS VALORES DA MATRIZ"
PARA I<-1 ATÉ 7 FAÇA
INÍCIO
    PARA J<-1 ATÉ 7 FAÇA
    INÍCIO
        LEIA A[I,J]
    FIM
FIM
PARA I<-1 ATÉ 7 FAÇA
INÍCIO
    MAIOR[I]<-A[I,1]
    PARA J<-2 ATÉ 7 FAÇA
    INÍCIO
        SE A[I,J]>MAIOR[I] ENTÃO
        INÍCIO
            MAIOR[I]<-A[I,J]
        FIM
    FIM
FIM
PARA J<-1 ATÉ 7 FAÇA
INÍCIO
    MENOR[J]<-A[1,J]
    PARA I<-2 ATÉ 7 FAÇA
    INÍCIO
        SE A[I,J]<MENOR[J] ENTÃO
        INÍCIO
            MENOR[J]<-A[I,J]
        FIM
    FIM
FIM
ESCREVA "MATRIZ"
PARA I<-1 ATÉ 7 FAÇA
INÍCIO
    PARA J<-1 ATÉ 7 FAÇA
    INÍCIO
        ESCREVA A[I,J]
    FIM
FIM
ESCREVA "MAIOR ELEMENTO DE CADA LINHA"
PARA I<-1 ATÉ 7 FAÇA
INÍCIO
    ESCREVA MAIOR[I]
FIM
ESCREVA "MENOR ELEMENTO DE CADA COLUNA"
PARA J<-1 ATÉ 7 FAÇA
INÍCIO
    ESCREVA MENOR[J]
FIM
FIM_ALGORITMO.
