1. Par ou ímpar: Utilize o operador de módulo (% 2). Se o resto da divisão por 2 for igual a 0, o número é par; caso contrário, é ímpar.

2. Positivo, negativo ou zero: Empregue uma estrutura encadeada (if, else if, else) para testar se o número é estritamente maior que 0, menor que 0 ou igual a 0.

3. Maior entre dois números: Compare os valores usando o operador relacional maior que (>) e exiba o resultado correspondente.

4. Maior entre três números: Utilize comparações aninhadas ou combine condições com o operador lógico E (&&) para verificar exaustivamente qual valor se sobressai.

5. Aprovação escolar: Crie uma condição simples avaliando se a nota final é maior ou igual a 7 (nota >= 7).

6. Aposentadoria: Verifique se a idade informada atinge ou ultrapassa o limite mínimo de 65 anos (idade >= 65).

7. Múltiplo de 5: Aplique o operador de resto dividindo por 5 (numero % 5 == 0) para confirmar a exatidão da divisão.

8. Divisível por 3 e 4: Conecte duas condições de divisibilidade simultâneas utilizando o operador lógico && (num % 3 == 0 && num % 4 == 0).

9. Voto obrigatório: Delimite o intervalo de obrigatoriedade combinando duas restrições com && (idade >= 18 && idade <= 70).

10. Triângulo válido: Valida-se a existência de um triângulo quando a soma de quaisquer dois lados é sempre maior que o terceiro (a + b > c && a + c > b && b + c > a).

11. Tipo de triângulo: Após validar que os lados formam um triângulo, verifique se todos são iguais (equilátero), se dois são iguais (isósceles) ou se todos são diferentes (escaleno).

12. Desconto em compras: Construa uma escada de decisões decrescente (if-else if-else), testando primeiro o patamar acima de R$ 500, depois a faixa entre R$ 200 e R$ 500, e deixando o caso base para valores abaixo de R$ 200.

13. Ordem crescente de três números: Implemente uma lógica de cruzamento de variáveis utilizando if-else para determinar manualmente qual é o menor, o intermediário e o maior valor, sem utilizar funções de ordenação prontas.

14. Conversão de notas em conceitos: Estruture uma cadeia de if-else if que avalie a nota do maior patamar (>= 9) para o menor (< 6).

15. Calculadora com operação informada: Leia a operação como caractere (char) ou string e utilize um switch-case ou múltiplos if para direcionar para a conta matemática correta (+, -, *, /).

16. Igualdade com o terceiro: Compare o terceiro número com o primeiro ou com o segundo utilizando o operador lógico OU (||) combinado com ==.

17. Mesma paridade: Avalie se o resto da divisão por 2 do primeiro número é idêntico ao resto da divisão por 2 do segundo (num1 % 2 == num2 % 2).

18. Ano bissexto: Utilize a regra lógica completa com precedência de operadores: (ano % 4 == 0 && ano % 100 != 0) || (ano % 400 == 0).

19. Cálculo de IMC: Calcule o índice usando a fórmula peso / (altura * altura) e categorize o resultado com uma estrutura if-else if nas faixas estabelecidas.

20. Classificação múltipla: Avalie o número em três frentes independentes: o sinal (positivo, negativo ou zero), a paridade (par ou ímpar) e a tipagem (verificando se há parte decimal, por exemplo, comparando o valor com sua conversão inteira).

21. Menu de café da manhã: Utilize a estrutura switch-case associando o número digitado pelo usuário (1 a 4) ao item de cardápio correspondente.

22. Calculadora com menu: Apresente opções numéricas para as operações aritméticas básicas, solicite os dois números e processe a escolha do usuário por meio de um switch-case.

23. Escolha de transporte: Empregue um switch-case para mapear a opção numérica escolhida (1 a 4) à respectiva velocidade média cadastrada.

24. Conversor de moedas: Utilize um switch-case para identificar a moeda de destino selecionada e multiplique o valor inserido pela cotação fixa correspondente.

25. Área de figura geométrica: Monte um menu com switch-case para a seleção da figura (círculo, quadrado ou retângulo), solicite estritamente as medidas exigidas por aquela figura específica e calcule a área com a fórmula matemática adequada.
